# 截图与宣传图

商店至少要求 **1 张截图**；建议 3–5 张。当前仓库没有任何截图，这是提交前的硬缺口。

## 规格

| 素材 | 尺寸 | 数量 | 状态 |
|---|---|---|---|
| 图标 | 128×128 PNG | 1 | 已有 `public/icon/128.png` |
| 截图 | 1280×800 **或** 640×400，PNG/JPEG | 1–5 | **缺** |
| 小型宣传图 | 440×280 | 0–1 | 缺，可选 |
| 大型宣传图 | 1400×560 | 0–1 | 缺，可选 |

截图必须展示扩展的真实界面，不得拼接虚假功能；可以在图上加简短标注，但不能遮挡关键 UI。

## 建议的 5 张

| # | 画面 | 要点 |
|---|---|---|
| 1 | 视频页 + 日语字幕特写 | 词性配色、振假名、词汇卡同时入镜；选画面干净的一帧 |
| 2 | 播放页控制面板 | 原文/译文、偏移、显示时长、样式 |
| 3 | 选项页「字幕包」 | 多番剧分包 + kitsunekko 来源信息 |
| 4 | 工具栏弹窗 | 当前页、字幕搜索、学习设置三块信息 |
| 5 | 学习模式对比 | 译文 0.5s 淡出、原文常显的状态说明 |

## 拍摄方法

1. `pnpm build` 后在 Chrome 加载 `.output/chrome-mv3`。
2. 窗口设为 1280×800（或用 DevTools → Device toolbar → Responsive 1280×800），`devicePixelRatio` 保持 1。
3. 准备一个字幕包并套用到视频页，摆好位置。
4. 用系统截图截取**页面区域**（不含浏览器边框），导出 PNG。
5. 逐张检查：无个人信息、无未授权影视画面水印、字迹清晰。

> 截图里出现的影视画面属于第三方版权内容。商店允许“展示扩展功能”的截图，但优先选自有视频或明确可再用的素材；不确定时用 MDN / W3C 的示例视频页。
