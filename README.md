# Visual Grammar Subtitles

Visual Grammar & Color-Coded Language Learning

在任意网页视频上叠加本地字幕的 Chrome 扩展，把字幕变成可视化语法课：词性着色、振假名、双层字幕、显示时长裁剪。

## 安装

```bash
pnpm install
pnpm build
```

Chrome → `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选择本项目的 `.output/chrome-mv3/` 目录。

## 使用

1. 打开任意带视频的页面（例：`https://www.deyunshucai.com/cid/96527-1-1.html`），鼠标移到画面上。
2. 右上角出现 `字` 按钮 → 打开设置面板。
3. **推荐先导入字幕库**：`chrome://extensions` → 本扩展 →「扩展程序选项」（或面板里的「字幕管理」）→ 导入 `.srt` / `.vtt` / `.ass`。
   字幕按番剧归包：一次选多个文件或直接导入整个文件夹，都会进同一个包，播放页按包分组选择，不会和别的剧混在一起。
   - 选项页首屏「字幕包」的第一块就是「在线获取 · kitsunekko」：输入标题（中/日文会自动翻译成英文一并搜索，如 `怪物` → `Monster`，查询词会发往 Google 翻译）→ 选系列 → 点压缩包「下载并导入为包」，整包字幕自动解包归入该番剧的包。索引约 600KB，本地缓存 24 小时。
   - 每个包都记录来源：kitsunekko 的系列路径、压缩包名、上传时间与链接；本地导入则记录文件夹 / 包名。重复导入同一系列会合并进原包并更新来源。
4. 也可以点「原文 → 文件」直接选本地字幕，或直接把字幕文件拖进画面区域。
   - 同一个页面路径的字幕、偏移、样式会自动保存，下次打开自动恢复。
   - 注意配置按「页面路径」保存：`.../96527-1-1.html` 与 `.../96527-1-2.html` 是两个独立记录。
5. 选项页勾选「新页面自动套用上次字幕」后，未加载字幕的页面会自动用清单里最后一次选中的那份（适合连续追剧）。
6. 「译文 文件 / 清单」可再加载一份中文字幕，形成原文 + 译文双层。
7. 字幕框的手柄只在指针移动时出现：左上角 `⠿` 拖动位置（双击复位）；右边手柄调宽、下边手柄调高、右下角同时调宽高（双击各自复位）。

### 工具栏弹窗

点击工具栏图标打开精简面板，覆盖常用操作，不用进选项页：

- **当前页**：显示站点规则匹配到的系列 / 集数与已绑定字幕包；「面板」直接调出播放页右上角面板。
- **字幕**：一个搜索框同时搜本地字幕包与 kitsunekko —— 本地结果带包裹图标排在前面，在线结果带地球图标；展开包点「套用」把该集字幕载入当前页（自动记录关联，站点规则下同时写入番剧绑定），在线结果进系列目录后可直接导入为包。
- **站点**：列出站点规则，可快速启停、打开配置了具体域名的站点；底部直达「站点规则 / 番剧绑定 / 完整设置」。
- **学习**：查词开关、JLPT 等级、触发方式、卡片持续时长、发音显示，改动即时写入，播放页立即生效。
- **主题**：浅色 / 深色 / 跟随系统，与选项页侧栏的选择共用一份设置。

### 界面语言

选项页侧栏「外观」下有 `中文` / `English` 切换，默认跟随浏览器语言（中文 → 简体中文，其余 → 英式英语），弹窗、选项页与播放页面板即时切换。扩展名称与描述由 Chrome 按**浏览器界面语言**渲染，切换后需重启浏览器或不随应用内设置变化。

### 学习模式（重点项目）

- **译文显示** 填 `500`：译文只在每句开头显示 0.5 秒后淡出，原文保持常显 —— 先看中文，字幕消失后靠听音频在大脑里对上号。
- **原文显示** 填 `0`：跟随字幕的原始结束时间。
- 视频暂停时不受显示时长限制，方便逐句精听。
- 拖动进度条后计数从落点重新开始：跳到句中也会重新显示一段，不会因为句中起算而整句不出现。

### 快捷键（页面内生效，需在视频所在页面获得焦点）

| 快捷键 | 作用 |
| --- | --- |
| `Alt` + `[` / `]` | 时间偏移 ∓0.1s（按住 Shift 为 0.5s）。正值 = 字幕整体延后 |
| `Alt` + `\` | 显示/隐藏译文层 |
| `Alt` + `P` | 重新显示当前句 1.8 秒 |
| `Alt` + `Enter` | 回到当前句开头重听 |
| `Alt` + 方向键 | 移动原文层位置 1% |
| `Alt` + `=` / `-` | 原文层字号 ±0.002（按住 Shift 为 ±0.006） |
| `Alt` + `S` | 跳过并标记广告：前进该剧集设定的秒数（默认 15），并记录为本集广告位 |

## 词性配色

| 词性 | 颜色 |
| --- | --- |
| 名詞 | `#1E90FF` 蓝 |
| 動詞 | `#E5533D` 红（非基本形有下划线并变暗） |
| 形容詞 / 形状詞 | `#B8860B` 琥珀 |
| 助詞 / 助動詞 | `#8A8F98` 灰 |
| 副詞 | `#0F9D58` 绿 |
| 接続詞 | `#9B59B6` 紫 |

配色按可读性挑选：字幕是大号加粗文字，WCAG AA 要求 ≥3:1；每个颜色都落在中间亮度区间，对白底和近黑底色（`#101014`）都 ≥3:1，再叠加字幕层原有的黑色描边阴影，避免亮画面下浅色字看不清。

分词使用 `@sglkc/kuromoji`（IPADIC），在 background service worker 中运行，词典随扩展打包（`.output/chrome-mv3/dict/`，约 14MB），完全离线。

## 词汇卡（日语 / 英语 / 泰语）

- 日语：字幕里命中 JLPT 词表的词带虚线下划线，弹出词汇卡：读音、级别、词性、英文释义、例句，以及按句朗读（系统日语语音）。
- 选项页「学习词典」可整体开关，并按 N1–N5 勾选要标注的级别；改动在播放页立即生效，无需刷新。
- 触发方式可选「点击单词」或「悬停即显示」；卡片持续可选「跟随字幕」（字幕换行/消失时关闭）或「固定时长」1–30 秒。
- 词表由 `pnpm dict:build` 从 JMdict 与 open-anki-jlpt-decks 生成到 `public/dict/jlpt-dict.json`（约 1.8MB，已提交，构建无需联网）。数据来源与许可见 [NOTICE.md](NOTICE.md)。
- 英语：`pnpm lexicon:build en` 从 ECDICT 生成 `public/dict/en/lexicon.json`；来源、字段映射与限制见 [docs/dict/en.md](docs/dict/en.md)。
- 泰语：`pnpm lexicon:build th` 合并人工审核的中文词表与 kaikki.org 泰语数据生成 `public/dict/th/lexicon.json`；审核规则、许可与限制见 [docs/dict/th.md](docs/dict/th.md)。
- 未收录词、助词 / 助动词、被 kuromoji 拆开的复合词片段不可点击。

## 站点规则（自动选集 / 广告补偿）

选项页「站点规则」用模板描述平台 URL，不写正则；规则全部存在本地，换站点只改配置不改代码。

内置规则：

- **bilibili 番剧**：模板 `https://*.bilibili.com/bangumi/play/*`。URL 里的 `ep510759` / `ss41417` 不携带集数，扩展会经后台向 bilibili 番剧接口查询季 ID、番剧名与集数（缓存 10 分钟），所以打开 `https://www.bilibili.com/bangumi/play/ep510759?from_spmid=...` 就能识别为「夏日重现 · 第 1 集」。番剧内切集由 URL 轮询跟随（2.5 秒内）。
- **hntaihoo**：`https://*/cid/<id>-<season>-<episode>.html`，集数直接从 URL 读。

- **URL 模板**：`<id>` 系列、`<season>` 季、`<episode>` 集、`*` 任意段。例：`https://*/cid/<id>-<season>-<episode>.html`，域名写成 `*` 后同一平台的别名域名共用一条规则。
- **解析测试**：粘贴一个页面 URL，实时显示 `id / season / episode`；内置规则还会显示解析出的番剧名与集数。
- **字幕文件名模板**：可选，留空用内置启发式（`S01E01`、`第5話`、`EP05`、`05`、`12v2` 等）。
- **广告位**：内嵌广告按「开始 + 结束」记录（如 `08:17` → `08:47`，超过 1 小时用 `1:08:17`），是字幕时间轴上的正片时刻，不是播放器秒数。广告时段内字幕冻结在开始时刻，广告结束后自动恢复到正确位置，不需要再手动调偏移；点击标记开始后到标记结束前同样冻结，结束后立即重排时间轴。播放页「字幕设置 → 广告标记」用两个图标分别记录开始与结束，已标记的段以横向小卡片列出，每张卡片可直接改起止或点 × 删除；没有任何记录时该行不占高度。系列默认广告位不做平台统一，也不手填，而是由该系列所有已标记剧集汇总得出：开始时刻与结束时刻各自按 6 秒内视为同一广告做聚类，取各簇均值；平均后仍重叠的簇合并为一段。所以每集可以标记不同位置的广告，标记的集越多系列默认越贴近实际，未标记的集直接用这份均值。选项页「站点规则 → 广告位 · 按剧集」按系列分组展示这张表：系列头是自动汇总的默认值，每集一行可增删广告段，支持按系列或集号筛选，底部一行可直接补录「系列 ID / 季 / 集 / 起止」。标题栏的双箭头图标切换自动跳过：播放进入已标记的广告时段直接跳到结束点，字幕时间轴按插入点续接，不产生偏移（默认开启，跨页面共用一份设置）。

**番剧绑定**：`系列 ID → 字幕包`（bilibili 用季 ID，如 `bilibili#41417`）。第一次在播放页手动选包时自动写入，之后打开该系列任意一集都会自动选中对应集数的字幕。首次进入未绑定过的番剧时还会用番剧名匹配同名字幕包并自动绑定；bilibili 番剧名是中文、kitsunekko 包名是英文 / 罗马音，自动匹配不上就手动选一次（在线搜索会自动把中文名英译）。选项页可直接编辑、补录或删除，也可导出 / 导入整份规则 JSON。

匹配优先级：本页历史关联 → 站点规则自动选集 → 「自动套用上次字幕」。任一步失败都退回手动选择，不影响播放。

## 实现要点

- 视频可能在跨域 iframe 内（目标站点就是这样），因此内容脚本以 `all_frames: true` + `<all_urls>` 注入，只按 `<video>` 元素锚定，不依赖站点 DOM。
- 字幕渲染在 Shadow DOM 中，`position: fixed` 跟随 `video.getBoundingClientRect()`，并按 `videoWidth/videoHeight` 做 letterbox 内缩，避免字幕落在黑边上。
- 页面配置以 tab 顶层 URL（经 background 取 `sender.tab.url`）为 key，因此同一部剧的每一集互不干扰。

## 已知限制

- 首次加载字幕时背景 worker 要构建词典，约 2–4 秒后首句才带颜色；之后按句缓存，无延迟。
- ASS 只解析 Dialogue 文本，不还原定位/特效/卡拉 OK 标签。
- 若播放器全屏的是 `<video>` 元素本身（而非容器 div），字幕层无法显示 —— 目标站点全屏的是容器，不受影响。
- 时间偏移是整条字幕的全局值；内嵌广告造成的分段偏移只能通过「站点规则 → 广告位 · 按剧集」或播放页的广告面板补偿，识别不到的平台仍需手动微调。

## 开发

```bash
pnpm dev            # WXT 开发模式，改完在扩展页点刷新
pnpm build          # 产出 .output/chrome-mv3
pnpm zip            # 同上，并打包为 .output/*.zip
pnpm typecheck      # tsc --noEmit
pnpm test           # Vitest 纯函数测试
pnpm storybook      # 设计系统 Storybook（localhost:6006）
pnpm e2e            # Playwright，需先 pnpm build
pnpm dict:build     # 重新生成 public/dict/jlpt-dict.json（联网，约 130MB 下载）
```

### 批量抓取字幕（kitsunekko）

```bash
node scripts/fetch-subtitles.ts Monster --list                    # 列出该系列全部字幕包
node scripts/fetch-subtitles.ts Monster --out subtitles/Monster   # 下载最新的一份，解包写入目录
node scripts/fetch-subtitles.ts Monster --file "Webrip).v2"       # 指定字幕包
```

只依赖 Node 22 内置的 `fetch` 与 `DecompressionStream`，与扩展共用 `src/features/scraper/`。中文 / 日文标题会自动翻译成英文一并搜索，与扩展行为一致。

脚本把一套字幕写进 `subtitles/<番剧>/`，并生成 `source.json` 记录来源（系列路径、压缩包名 / 链接 / 上传时间、文件清单），保证整包可追溯。

调试：内容脚本在隔离环境中暴露 `__jpSub`（`__jpSub.setSubtitle(srtText)`、`__jpSub.tokenize(text)`、`__jpSub.config`），在 DevTools 控制台（选中视频所在的 frame）可直接调用。
