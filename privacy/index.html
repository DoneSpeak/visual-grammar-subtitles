Privacy Policy

JP Subtitle Overlay · Effective 31 October 2026

JP Subtitle Overlay (“the extension”) is a browser extension that displays user-supplied subtitle files over videos on web pages and adds Japanese reading aids. This policy describes what the extension accesses, what it stores on your device, and the limited cases in which it makes network requests.

Summary: the extension has no user accounts, no analytics, no advertising and no developer-operated servers. Everything you import stays in your browser’s local extension storage. Network requests occur only when you use the online subtitle import, when a search query needs translation, or when you connect an optional analysis server that you configure yourself.

1. Data stored on your device

The extension uses chrome.storage.local. This data stays on your device and is not synchronised to Google or to the developer.

  • Preferences: interface language, theme, subtitle appearance, timing offsets, learning/dictionary settings, shortcut settings.
  • Subtitle library: files you import, their parsed text, pack titles, episode names and the source URL or folder recorded at import time.
  • Per-page state: the subtitle selected for a page path, its offset, and markers you create for advertisement segments.
  • Site rules and series bindings that you create.
  • Caches: the online subtitle index (24-hour cache), offline dictionary data bundled with the extension, and analysis results if you use an optional analysis server.
  • If you configure an optional analysis server: its address and the access token you enter.

You can delete this data from the extension’s options page, or remove all of it by uninstalling the extension.

2. Web page access

The extension runs a content script on all sites because a video can appear on any page. On a page it:

  • locates <video> elements and reads their geometry, playback state and time so the subtitle layer can be positioned and synchronised;
  • reads the page URL and title to restore per-page subtitle settings;
  • on Bilibili video pages, reads the season or episode identifier present in the page URL;
  • reads subtitle text that you load into the extension, and page text only where needed to attach the overlay and word card.

It does not read form inputs, passwords, messages, or other page content unrelated to video playback and subtitle display. Browsing history is not recorded or transmitted.

3. Network requests

The extension has no backend. The following requests are made from your browser, only in the situations described:

  • kitsunekko.net — when you search or import subtitles from the online catalogue. The search query and the requested directory or archive paths are sent to that site; subtitle files are downloaded to local storage.
  • translate.googleapis.com — when the online search query contains Japanese or Chinese characters, the query text is sent to Google’s public translation endpoint so it can be searched by English title. Only the query string is sent. The response is cached in memory for the session.
  • api.bilibili.com — on Bilibili pages, the season or episode identifier read from the page is sent to resolve the series title and episode list. The response is cached in memory for 10 minutes.
  • An analysis server you configure (default http://127.0.0.1:8765) — only if you enable the optional local/remote NLP analysis feature. Subtitle lines and an access token are sent to that address. The developer does not operate this server and does not receive this data; the address is entirely under your control.

There are no analytics, telemetry, crash reports, advertising, fingerprinting, or remote configuration requests. The extension does not load or execute remote code; all JavaScript is bundled in the package.

4. Speech synthesis

Word and sentence pronunciation uses the browser’s built-in speechSynthesis API and the voices installed on your operating system. The extension sends no audio or text to a speech service.

5. Sharing, sale and use

The developer does not receive, sell, rent, or share your data. Data is not used for advertising, profiling, creditworthiness, or any purpose unrelated to subtitle display. Third-party sites listed in section 3 receive only the specific request described there and handle it under their own privacy policies.

6. Retention and deletion

Imported subtitles, settings and caches remain on your device until you remove them in the options page or uninstall the extension. Uninstalling removes chrome.storage.local. Because the developer holds no copy, there is no server-side deletion request to make.

7. Security

Requests to third-party services use HTTPS. No credentials are sent to the developer. The optional analysis-server token is stored locally and is only sent to the endpoint you configure, over the transport that endpoint uses.

8. Children

The extension is not directed at children under 13 and does not knowingly collect personal information from anyone.

9. Changes

Material changes to this policy will be published on this page with a new effective date, and the extension’s store listing will link to the updated version.

10. Contact

Questions about this policy: guanrong.young@foxmail.com

隐私政策

日语字幕叠加 · 生效日期 2026 年 10 月 31 日

「日语字幕叠加」（下称“本扩展”）是一个浏览器扩展，在网页视频上显示用户自备的字幕文件，并提供日语阅读辅助。本政策说明扩展访问什么、在你的设备上保存什么，以及仅在哪些情况下会发起网络请求。

摘要：本扩展没有账号、没有统计、没有广告，也没有开发者运营的服务器。你导入的内容保存在浏览器本地的扩展存储中。只有在你使用在线字幕导入、搜索词需要翻译，或你自己配置了可选的分析服务时，才会发起网络请求。

1. 保存在设备上的数据

本扩展使用 chrome.storage.local，数据留在你的设备上，不会同步到 Google 或开发者。

  • 偏好设置：界面语言、主题、字幕外观、时间偏移、学习/词典设置、快捷键设置。
  • 字幕库：你导入的文件、解析后的文本、包标题、集名，以及导入时记录的来源链接或文件夹。
  • 页面状态：按页面路径保存的字幕选择、偏移，以及你标记的广告区间。
  • 你创建的站点规则与番剧绑定。
  • 缓存：在线字幕索引（缓存 24 小时）、随扩展打包的离线词典数据，以及使用可选分析服务时的分析结果。
  • 若你配置了可选的分析服务：其地址和你填写的访问令牌。

你可以在选项页删除这些数据，或卸载扩展以全部移除。

2. 网页访问

由于视频可能出现在任何网站，扩展会在所有站点运行内容脚本。在页面上它只会：

  • 定位 <video> 元素，读取其位置尺寸、播放状态与时间，用于定位和同步字幕层；
  • 读取页面 URL 与标题，用于恢复该页面的字幕设置；
  • 在 B 站视频页读取 URL 中的季/集标识；
  • 读取你载入扩展的字幕文本，以及为挂载字幕层与词汇卡所必需的页面内容。

它不读取表单输入、密码、消息或其他与视频播放和字幕显示无关的页面内容，也不记录或发送浏览历史。

3. 网络请求

本扩展没有后端。以下请求由你的浏览器发出，且仅发生在所述场景：

  • kitsunekko.net — 当你使用在线字幕搜索或导入时，搜索词与请求的目录/压缩包路径会发送到该站点，字幕文件下载后保存在本地。
  • translate.googleapis.com — 当在线搜索词包含日文或中文字符时，搜索词会发送到 Google 的公开翻译接口，以便用英文标题检索。仅发送该搜索词，结果仅在本会话内存中缓存。
  • api.bilibili.com — 在 B 站页面，从 URL 读取的季/集标识会发送以获取剧集信息，结果在内存中缓存 10 分钟。
  • 你自行配置的分析服务（默认 http://127.0.0.1:8765）— 仅当你启用可选的本地/远程 NLP 分析时，字幕行与访问令牌会发送到该地址。开发者不运营该服务、也收不到这些数据；地址完全由你控制。

本扩展没有统计、遥测、崩溃上报、广告、指纹识别或远程配置请求，也不加载或执行远程代码；所有 JavaScript 均打包在安装包内。

4. 语音合成

单词与句子的朗读使用浏览器内置的 speechSynthesis 接口和操作系统已安装的语音。扩展不向语音服务发送音频或文本。

5. 共享、出售与使用

开发者不接收、出售、出租或共享你的数据。数据不用于广告、画像、信用评估或与字幕显示无关的任何目的。第 3 节列出的第三方站点只会收到该节描述的具体请求，并按各自的隐私政策处理。

6. 保留与删除

导入的字幕、设置与缓存会一直保存在你的设备上，直到你在选项页删除或卸载扩展。卸载会清除 chrome.storage.local。由于开发者不持有副本，不存在需要向服务器申请删除的数据。

7. 安全

对第三方服务的请求使用 HTTPS。不会有凭据发送给开发者。可选分析服务的令牌保存在本地，只会发送到你配置的端点，并使用该端点自身的传输方式。

8. 儿童

本扩展不面向 13 岁以下儿童，也不会明知地收集任何人的个人信息。

9. 变更

本政策的实质性变更会发布在本页并更新生效日期，商店条目会链接到更新后的版本。
