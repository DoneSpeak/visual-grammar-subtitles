# 泰语字幕六种学习模式（Thai Subtitle Learning Modes）

> 特性说明｜适用于现有 Chrome Extension 字幕学习功能。
>
> 本文仅定义学习模式、泰语案例与渲染表现，不是完整 PRD。

## 1. 设计定位

泰语与英语、日语共用字幕解析和渲染的基本框架，但学习重点不同：

| 维度 | 英语 | 日语 | 泰语 |
| --- | --- | --- | --- |
| 词汇边界 | 以空格分词为主 | 依赖形态分析 | 词之间通常不使用空格，需要分词 |
| 基本语序 | SVO | SOV | SVO |
| 动词语法 | 时态、情态、语态等 | 活用、助词、句末表达 | 动词通常不屈折变化，借助功能词表达时体、语气等 |
| 发音关注 | 重音、弱读、连读 | 音拍、音调 | 五个声调、元音长短、音节 |
| 字幕学习重点 | 搭配、从句、句子成分 | 助词、活用、语气 | **分词、语义组块、时体与功能词、发音声调** |

**设计原则：**共享 Token、Phrase、Clause、Pronunciation、Expression 等分析概念；根据泰语特点定义独立的学习模式和标注重点。不应将英语主谓宾着色方案原样套用到泰语。

## 2. 统一案例字幕

**泰语：**

> ถ้าเหนื่อยก็พักก่อน เดี๋ยวฉันช่วยเอง

**中文：**累了就先休息一下，待会儿我来帮你。

这是为功能说明编写的**原创日常口语示例，不是影视作品原句**。它包含条件结构、隐含主语、时间表达、主谓结构与主动承担的语气，长度适合字幕展示。

## 3. 六种字幕学习模式

### 模式 1：词汇边界（Word Segmentation）

**定义：**明确展示泰语单词边界，让用户能够识别原本连续书写的词。

**原文：**

`ถ้าเหนื่อยก็พักก่อน เดี๋ยวฉันช่วยเอง`

**词级拆分：**

`ถ้า | เหนื่อย | ก็ | พัก | ก่อน | เดี๋ยว | ฉัน | ช่วย | เอง`

| 词 | 释义 |
| --- | --- |
| ถ้า | 如果 |
| เหนื่อย | 累 |
| ก็ | 就、那么 |
| พัก | 休息 |
| ก่อน | 先 |
| เดี๋ยว | 待会儿、即将 |
| ฉัน | 我 |
| ช่วย | 帮助 |
| เอง | 自己、亲自 |

**渲染表现：**按词用交替颜色、轻量背景或下划线展示边界；点击词可查看含义。应保留原始字幕的空格与停顿，不把可视化边界写回字幕原文。

**学习价值：**理解 `พักก่อน` 可以拆成 `พัก`（休息）+ `ก่อน`（先），而不是将连续文字视为一个未知长词。

### 模式 2：语义组块（Chunking）

**定义：**按照表达的意义将字幕组合为容易理解和记忆的单元，避免逐词翻译。

| 语义组块 | 整体意义 |
| --- | --- |
| ถ้าเหนื่อย | 如果累了 |
| ก็พักก่อน | 就先休息 |
| เดี๋ยว | 待会儿 |
| ฉันช่วยเอง | 我来帮忙 |

**渲染表现：**对组块整体着色或加背景；可在暂停或选中时显示组块释义。语义组块并不一定与严格句法节点一一对应。

**学习价值：**从“识别每个词”过渡到“直接理解表达”。

### 模式 3：句法结构（Syntax）

**定义：**识别条件从句、结果主句，以及话语中的主语、谓语与修饰关系。

```text
ถ้าเหนื่อยก็พักก่อน  เดี๋ยวฉันช่วยเอง
├─ ถ้าเหนื่อย         条件从句：如果累了
├─ ก็พักก่อน          结果主句：就先休息
└─ เดี๋ยวฉันช่วยเอง   后续话语：待会儿我来帮忙
   ├─ เดี๋ยว          时间/即将
   ├─ ฉัน             主语
   ├─ ช่วย            谓语
   └─ เอง             强调亲自承担
```

**注意：**前半句的主语没有明确出现，需要结合语境理解；后半句的主语 `ฉัน` 是显式的。`ช่วย` 的受益对象由语境理解，不应凭空制造一个原文里不存在的宾语。

**渲染表现：**将条件、结果、后续话语分层标注；需要时展开主语、谓语和修饰关系，而非在播放画面上同时展示完整语法树。

**延伸关注：**泰语还存在连续动词结构，例如 `ไปซื้อกาแฟ`（去买咖啡），不能仅因多个动词连续出现就拆成多个独立句子。

### 模式 4：时体与功能词（Aspect & Particles）

**定义：**突出泰语通过独立功能词表达条件、时序、持续状态、意图与语气的方式，而非主要依赖动词词尾变化。

**本句示例：**

| 形式 | 功能 | 理解 |
| --- | --- | --- |
| ถ้า | 条件 | 如果 |
| ก็ | 承接条件结果 | 那么、就 |
| ก่อน | 动作顺序 | 先 |
| เดี๋ยว | 时间或即将发生的动作 | 稍后、待会儿 |
| เอง | 强调行动者本人 | 我亲自来 |

**另一典型结构：**

> ฉันกำลังกินข้าวอยู่
>
> 我正在吃饭。

其中 `กำลัง ... อยู่` 可以配合表达动作的进行状态；这组标注的两个部分**不连续**，中间包含其他词。

**渲染表现：**只给关键功能词进行轻量突出；允许同一语法表达绑定多个不连续的 token。此模式不仅包含严格意义上的“时体”，也涵盖条件、顺序、强调等功能词。

### 模式 5：音节与声调（Pronunciation）

**定义：**在词级信息之外，提供音节、声调、元音长短等发音学习信息，将文字理解与听辨、跟读联系起来。

**示例：**

`ภาษาไทย`（泰语）

音节分解：`ภา | ษา | ไทย`（3 个音节）。

**渲染表现：**

- 字幕正常播放时，只提供轻量音节边界或发音提示。
- 点击词或音节后，展开读音、IPA（如有可靠数据）、声调、元音长度与音频播放。
- 声调信息必须来自可信规则、词典或经验证的分析结果；不要简单根据文字颜色推断准确发音。

**学习价值：**帮助学习者区分“认识词形”与“能够正确听出和读出词”。

### 模式 6：固定搭配与口语（Expressions）

**定义：**突出可直接迁移到日常对话的表达，包括常见句型、惯用语、礼貌表达与句末语气词。

**原句中的表达：**

| 表达 | 用法 |
| --- | --- |
| ถ้า...ก็... | 如果……就……的条件结构 |
| พักก่อน | 先休息一下 |
| เดี๋ยวฉัน...เอง | 待会儿我亲自……，表达主动承担 |

**补充口语案例：**

> ไม่เป็นไรนะ เดี๋ยวฉันช่วยเอง
>
> 没关系啦，待会儿我来帮你。

| 表达 | 学习要点 |
| --- | --- |
| ไม่เป็นไร | 没关系、不要紧，常见固定表达 |
| นะ | 这里柔化语气，使表达更亲切；实际效果依语境与语调变化 |
| เดี๋ยวฉันช่วยเอง | 我来帮忙，表达主动承担 |

**渲染表现：**按表达整体高亮；点击后展示自然含义、使用场景及语气说明，避免机械地逐字翻译。补充例句同样为原创教学案例。

## 4. 六种模式汇总

| 模式 | 核心问题 | 对应示例 | 优先级建议 |
| --- | --- | --- | --- |
| 词汇边界 | 哪些字符组成一个词？ | `ถ้า | เหนื่อย | ก็...` | 默认 |
| 语义组块 | 哪些词合起来表达一个意思？ | `ถ้าเหนื่อย` / `ก็พักก่อน` | 默认 |
| 句法结构 | 条件、主句、主谓关系是什么？ | `ถ้า...ก็...` / `ฉันช่วย` | 进阶 |
| 时体与功能词 | 如何表达时序、状态、语气？ | `ก่อน`、`เดี๋ยว`、`เอง`、`กำลัง...อยู่` | 进阶 |
| 音节与声调 | 如何听懂并读准？ | `ภาษาไทย` → `ภา | ษา | ไทย` | 专项 |
| 固定搭配与口语 | 如何把表达用在现实对话？ | `ไม่เป็นไรนะ` | 专项 |

## 5. 建议的字幕呈现方式

- **正常播放默认：**“词汇边界 + 语义组块”。先帮助用户看清词，再理解整段表达。
- **暂停后深入：**切换到“句法结构”或“时体与功能词”，查看句子内部的关系。
- **点击词或组块：**按需展开“音节与声调”或“固定搭配与口语”。
- **自定义样式：**继续支持字体、颜色、字号、背景色、下划线等，不要求所有标注同时展示。
- **重叠结构：**允许一个 token 同时属于词、组块和句法关系；允许语法标注跨越非连续 token。学习模式负责选择展示哪一层，不要求重新解析字幕。

## 6. 与英语学习模式的关系

| 学习维度 | 英语侧重点 | 泰语侧重点 |
| --- | --- | --- |
| 词汇边界 | 辅助理解 | 核心基础 |
| 语义组块 | 核心 | 核心 |
| 句法结构 | 主谓宾、从句、短语 | 主谓宾、条件、关系、连续动词 |
| 词形/功能 | 时态、情态、非谓语等 | 时体词、条件、顺序、语气 |
| 发音 | 重音、弱读、连读 | 音节、声调、元音长短 |
| 固定表达 | Collocations、Idioms | 惯用表达、礼貌与口语语气 |

**最终原则：**复用统一的分析结构及字幕渲染机制，但由泰语模式决定突出词界、组块、功能词和声调，而不是复制英语或日语的默认着色配置。
